# 柏林噪声算法深度解析 - 交互式演示课件

> 一个沉浸式的Web-based教学演示系统，通过可视化与交互式体验深入解析Perlin Noise（柏林噪声）算法的核心原理与应用场景。

## 项目概述

本项目是一个专为算法教学设计的交互式演示课件，旨在以直观、生动的方式呈现柏林噪声算法的诞生背景、数学原理与实际应用。通过7个精心设计的教学模块，配合实时可视化演示，帮助学习者快速掌握这一在计算机图形学领域具有里程碑意义的算法。

### 核心特性

- **沉浸式学习体验**：采用全屏16:9影院级比例，营造专注学习环境
- **多维度可视化**：通过Canvas实时渲染算法效果，将抽象概念具象化
- **模块化教学设计**：7个循序渐进的教学模块，从问题引入到实践应用
- **交互式探索**：支持参数调节、实时预览、动画演示等交互功能
- **现代化美学设计**：融合毛玻璃效果与悬浮卡片元素，呈现专业视觉效果

### 核心模块

1. **问题引入** - 从游戏开发实际需求出发，揭示算法诞生的必然性
2. **算法发明者** - 了解Ken Perlin的生平与奥斯卡获奖经历
3. **核心原理** - 深入剖析网格划分、梯度向量、点乘运算、插值平滑四步流程
4. **参数演示** - 实时调节频率、振幅、倍频等关键参数，观察效果变化
5. **对比分析** - 柏林噪声vs白噪声的可视化对比
6. **应用案例** - 探索在游戏、影视、科学计算等领域的实际应用
7. **总结扩展** - 回顾核心概念，提供进一步学习资源

### 设计亮点

- **毛玻璃视觉语言**：采用半透明背景与高斯模糊，创造层次分明的视觉深度
- **卡片化信息架构**：内容模块化呈现，降低认知负荷
- **悬浮阴影系统**：通过细腻的光影效果增强界面的空间感
- **无滚动全屏体验**：专为演示场景优化，确保内容完整呈现
