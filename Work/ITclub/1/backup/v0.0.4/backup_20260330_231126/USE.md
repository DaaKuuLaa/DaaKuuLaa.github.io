# 使用指南

> 本文档详细介绍柏林噪声交互式演示课件的使用方法、操作技巧和快捷键系统，帮助您充分发掘系统的教学价值。

## 一、快速入门

### 1.1 启动与访问

**本地运行**：
```bash
# 方法一：直接打开
双击 index.html 文件

# 方法二：使用HTTP服务器（推荐）
cd a:/Work
python -m http.server 8000
# 然后在浏览器访问 http://localhost:8000
```

**在线访问**：
将项目部署至Web服务器后，直接访问URL即可。

### 1.2 首次使用流程

1. **页面加载**：等待加载动画完成（约2-3秒）
2. **熟悉界面**：观察顶部导航栏布局
3. **开始探索**：点击第一个模块"问题引入"
4. **交互体验**：尝试调节参数、切换页面

### 1.3 系统要求

- **浏览器**：Chrome 80+ / Firefox 75+ / Edge 80+ / Safari 13+
- **分辨率**：1366×768 或更高（推荐 1920×1080）
- **内存**：≥4GB RAM
- **显卡**：支持硬件加速（确保Canvas流畅渲染）

## 三、交互操作

### 3.1 模块导航

**鼠标操作**：
- **单击模块按钮**：切换到对应模块
- **悬停模块按钮**：显示模块简介提示
- **点击方向箭头**：上一模块/下一模块

**键盘操作**：
- `←` 或 `→`：模块间左右切换
- `Home`：返回第一个模块
- `End`：跳转到总结模块

**触摸操作**（支持触摸屏设备）：
- 左右滑动：模块切换
- 点击页签：页面切换

### 3.2 页面导航

**页签切换**：
- 点击右侧圆形页签直接跳转
- 或点击上下箭头逐页浏览

**进度控制**：
- 每页底部显示当前页/总页数
- 完成当前模块所有页面后，模块标记为"已完成"

### 3.3 可视化交互

**Canvas区域操作**：

| 操作 | 说明 | 效果 |
|------|------|------|
| **悬停** | 鼠标移入Canvas | 显示工具提示 |
| **点击** | 单击Canvas区域 | 触发动画/重置 |
| **拖动滑块** | 调节参数 | 实时更新可视化 |
| **双击** | 快速双击Canvas | 放大/全屏查看 |

**控制按钮**：

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| 🔄 重新生成 | 生成新的随机数据 | `R` |
| ▶ 播放动画 | 播放算法演示动画 | `Space` |
| ⏸ 暂停 | 暂停当前动画 | `Space` |
| ⚙️ 参数面板 | 显示/隐藏参数控制 | `P` |
| 📊 切换视图 | 切换不同的可视化模式 | `V` |

### 3.4 参数调节

**滑块控制**：
- **操作**：鼠标拖动滑块或点击轨道
- **反馈**：数值标签实时更新，Canvas同步渲染
- **范围**：根据参数类型设置合理最小/最大值

**参数类型**：

1. **频率（Frequency）**：
   - 范围：0.001 - 0.1
   - 效果：控制噪声的密集程度

2. **振幅（Amplitude）**：
   - 范围：0.1 - 2.0
   - 效果：控制噪声的强度

3. **倍频（Octaves）**：
   - 范围：1 - 8
   - 效果：控制细节层次

4. **持久度（Persistence）**：
   - 范围：0.1 - 1.0
   - 效果：控制每层的贡献度

**预设模式**：
- 🏔️ **地形模式**：适合生成山脉地形
- 🌊 **云层模式**：适合模拟云层效果
- 🔥 **火焰模式**：适合创建火焰纹理
- 💎 **大理石模式**：适合大理石纹理

## 六、常见问题

### Q1: 页面显示不全，有内容被裁剪？

**原因**：屏幕分辨率低于1366×768

**解决方案**：
1. 按 `F11` 进入全屏模式
2. 调整浏览器缩放比例（`Ctrl` + `-`）
3. 更换更高分辨率的显示设备

### Q2: Canvas动画卡顿？

**原因**：显卡性能不足或硬件加速未开启

**解决方案**：
1. 关闭其他占用GPU的程序
2. 在浏览器设置中开启"硬件加速"
3. 降低参数复杂度（减少倍频数）
4. 刷新页面重试

### Q3: 毛玻璃效果不显示？

**原因**：浏览器不支持 `backdrop-filter`

**解决方案**：
1. 升级浏览器到最新版本
2. 在 `chrome://flags` 中启用实验性特性
3. 系统会自动降级为纯色背景（功能不受影响）

### Q4: 键盘快捷键无效？

**原因**：焦点不在演示页面上

**解决方案**：
1. 点击页面任意空白区域
2. 检查是否有模态框打开（按 `Esc` 关闭）
3. 确认未开启中文输入法

### Q5: 如何快速重置所有参数？

**方法**：
1. 按 `Ctrl + R` 刷新页面
2. 或点击"设置" → "重置所有参数"
3. 控制台输入 `resetAll()`

### Q6: 如何分享特定页面？

**方法**：
- 使用URL参数：`?module=3&page=2`
- 例如：`index.html?module=3&page=2` 直接打开模块3第2页
- 点击"分享"按钮生成带参链接
