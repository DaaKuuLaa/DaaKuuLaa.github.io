## 技术实现细节

### 噪声计算流程
1. **步骤 1**: 获取 4 个角点的点乘值（A、B、C、D）
2. **步骤 2**: 沿 X 轴插值，得到中间值 X1 和 X2
3. **步骤 3**: 沿 Y 轴插值，得到最终噪声值
4. **步骤 4**: 显示计算结果

### 动画系统
- 使用 `requestAnimationFrame` 实现流畅动画
- 动画进度：0-40 步，每步对应不同的计算阶段
- 速度控制：通过 `speed` 参数调节每帧进度增量
- 状态管理：支持暂停、重置和重新启动

### 平滑插值
```javascript
smoothstep(t) = 6t⁵ - 15t⁴ + 10t³
```
- 5 阶多项式确保导数连续
- s(0)=0, s(1)=1, s'(0)=s'(1)=0
- 实现自然平滑的过渡效果

### 线性插值
```javascript
lerp(a, b, t) = a + (b - a) * t
```
- 加权平均计算
- 用于 X 轴和 Y 轴插值
